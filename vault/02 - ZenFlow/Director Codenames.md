# Director Codenames

Set Oct 4, 2026. A Director codename names the division's **industry** and never uses a word from the division's own name. Codenames also avoid existing product names (Atlas Platform, Apex System, the SENTINEL hardware line, the VANTAGE terminal, PRISM AI, Aether Link's Mesh) so a name always points to one thing.

> [!note] Earlier sets
> Four naming sets existed in the Drive: the Master Agent Roster and July dossiers (AXIS, VANTAGE, ATLAS…), the God Prompt Library (ZEN, CONSULT, NEXUS…), the Obsidian Vault Matrix (SAGE, ORACLE, LEX, MIRROR…) and the Overseer Ecosystem Blueprint v2 role titles. AXIS, SIGNAL and TERRA meant different divisions in different sets. This table replaces all of them. SAGE, COMMONS, LEX and MIRROR carry over from the Drive.
