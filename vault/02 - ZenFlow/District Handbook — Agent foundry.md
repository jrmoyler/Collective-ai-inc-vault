# District Handbook — Agent foundry

## District purpose
Agent work begins with a scoped mandate, current routing, and an evidence trail. ZENITH is Tier 1 and routes or escalates; HATAALII is Tier 0.5.

Folder: 02 - ZenFlow. This handbook describes the virtual knowledge district, not a physical campus district.

## Work kit
- Read Agent Tier Registry and Director Codenames before assigning agent identities. June director names are historical.
- Define inputs, outputs, tools, memory scope, evaluation, and escalation for each blueprint.
- The 600-agent lattice is reference architecture. Report live connected agents from presence evidence rather than assuming every planned specialist runs.

## Required record fields
- Role and scoped mandate
- Input and output contracts
- Tool authorization and memory scope
- Aegis state, evaluation cases, and failure recovery

## Completion check
- The source and its effective date are recorded.
- Current facts and historical targets are distinct.
- Linked division and hub notes exist.
- The next action or unresolved question is stated.
- An existing note is extended before a duplicate is created.
