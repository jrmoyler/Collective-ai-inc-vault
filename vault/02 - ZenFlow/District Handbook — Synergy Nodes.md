# District Handbook — Synergy Nodes

## Purpose
Trace cross-division execution units, their dependencies, and phase-specific evidence.

This is a virtual knowledge district. It preserves original note folders and creates a curated route through their related subjects. It does not activate a division or establish a physical facility.

## Work sequence
1. Read a node mandate.
2. Inspect participating divisions.
3. Check phase and delivery evidence.
