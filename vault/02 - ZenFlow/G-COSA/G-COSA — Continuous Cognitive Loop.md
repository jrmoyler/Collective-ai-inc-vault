```text
6. The Cognitive Loop
G-COSA runs a continuous, closed-loop cycle on every Mac Mini:
1. Telemetry Ingest: Raw data from agents, markets, and human chats.
2. Curvature Detection: Estimates systemic stress (Ricci scalar, Fisher drift).
3. Regime Atlas Lookup: Identifies the current operational chart.
4. HGLAR Decomposition: Builds reasoning graphs for ambiguity.
5. HRM Inference: Bottom-up agent beliefs vs. Top-down directives.
6. Geodesic Planning + ARC-R: Computes least-disruptive execution path and couples relevant agents.
7. Natural Gradient Update: Safely adapts policies.
8. Symbiotic Governance + Commit: Checks your predefined autonomy limits, asks for WhatsApp/Terminal confirmation if needed, then executes via the sandboxed SKILL.md system.
```
