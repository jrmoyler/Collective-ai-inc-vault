```text
2. The 9-Layer G-COSA Architecture Stack
The system is organized into nine functional layers. Every interaction is communicated upward and downward through a standardized GeometricCognitiveFrame data structure.
Layer
	Name
	Function
	9
	600-Agent Execution Mesh
	Runtime execution of the 30 agents per Division Mac Mini. Handles tasks, trades, communications, and tool execution via local SKILL.md registries.
	8
	Natural Gradient Optimizer
	Geometry-aware parameter updates using Kronecker-factored Fisher Information metrics.
	7
	Curvature Detection + Geodesic Planner + ARC-R
	Senses instability, plans least-disruption trajectories, and coordinates dynamic coupling/decoupling of agent clusters.
	6
	Geometric Regime Atlas
	Persistent memory of manifold charts, known regimes, transition graphs, and curvature priors (stored globally on the Core nodes).
	5
	HRM Inference Substrate
	Hierarchical Reasoning Models. Multi-level reasoning across agents, clusters, divisions, global collective, and human context.
	4
	HGLAR Reasoning Framework
	Hierarchical Graph Learning and Reasoning. Decomposes ambiguity into hierarchical sub-questions, hypotheses, and evidence graphs.
	3
	COSA Executive Kernel
	The "Local Overseer" on each Mac Mini. Handles system mode selection, scheduling, routing, execution contracts, and audit logging.
	2
	MELD/ERC Affective-Social Sensing
	Emotion Recognition in Conversation. Tracks your stress, trust, urgency, and coordination friction via your text/commands.
	1
	Symbiotic AI Governance
	Human approval gates, autonomy policy, explanation contracts, and audit artifacts. Ensures agents remain aligned ("Malbot" prevention).
```
