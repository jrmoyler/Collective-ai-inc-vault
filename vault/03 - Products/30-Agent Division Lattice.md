# 30-Agent Division Lattice

**Division:** [[ZenFlow Division]] · **Type:** Agent Architecture Standard · **Status:** spec

## Description

The ZenFlow standard per division: 30-agent cluster with 3 Intake, 3 Research, 3 Strategy, 5 Build, 3 Review, 4 Automation, 3 Content/Comms, 3 Analytics, 2 Memory, 1 Orchestrator. Applied across all 20 divisions.

## Build / creation platform

Zenith OS Agent Foundry. Agent blueprints in ZenFlow's God Prompt format. Each agent on Anthropic Claude API / n8n / LangChain per role function.
