## Master Product Catalog entry

- **Division:** [[Cognara Mind Division]]
- **Type:** Research & Analytics Platform

**Description.** Portfolio-wide behavioral intelligence infrastructure. Tracks user behavior patterns across Collective AI products, runs behavioral studies from usage data, and distributes monthly behavioral intelligence reports to all 20 Division Directors.

**Build / creation platform.** Behavioral analytics via Mixpanel / Amplitude. Custom Python analytics for cohort behavior. Claude API for insight synthesis. Monthly report generation via automated pipeline. Privacy-compliant consent management via OneTrust.
