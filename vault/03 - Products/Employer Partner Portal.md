# Employer Partner Portal

**Division:** [[Nomad Nexus Division]] · **Type:** B2B Platform · **Status:** spec

## Description

Enterprise portal enabling employers to provide Nomad Nexus as a remote work benefit. Team destination coordination, visa compliance monitoring for remote employees, and coworking access management.

## Build / creation platform

Next.js admin portal. Supabase backend. HR system integration via API (Rippling, Workday). Visa compliance monitoring via automated alerts. Stripe for enterprise billing.
