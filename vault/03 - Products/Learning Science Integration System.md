# Learning Science Integration System

**Division:** [[Cognara Mind Division]] · **Type:** EdTech Framework · **Status:** spec

## Description

Application of cognitive learning science (spaced repetition, retrieval practice, interleaving) to Hybrid Living's curriculum design. Produces documented retention rate improvements.

## Build / creation platform

Learning science framework in Notion. Spaced repetition algorithm integrated into Atlas LMS. Assessment design templates. Retention analytics via Atlas platform dashboard.
