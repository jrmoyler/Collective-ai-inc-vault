## MVP plan

MVP brief: [[MVP — ZenFlow Marketplace]] (from [[MVP Build Guide]])

- Objective: External-facing marketplace where customers buy pre-built ZenFlow agent configurations and enterprise agent packages.
- Build platform: Next.js/React, FastAPI, Stripe, Zenith OS provisioning, Vercel + Docker.
- Priority: Phase 1/2; complexity: Medium
- Governance: Standard Aegis-Clear with privacy, audit logging, and role-based access controls.
- Timeline: 90 days in 5 phases; status planned.

## Master Product Catalog entry

- **Division:** [[ZenFlow Division]]
- **Type:** SaaS Marketplace

**Description.** External-facing agent marketplace. Individuals, SMBs, and enterprises purchase pre-built ZenFlow agent configurations. Pricing tiers: Solo Blueprint $1,250–$3,500 through Enterprise Engine $150K–$500K+.

**Build / creation platform.** Next.js / React frontend. FastAPI backend. Stripe for payments. Zenith OS for agent provisioning. Deployed via Vercel + Docker.
