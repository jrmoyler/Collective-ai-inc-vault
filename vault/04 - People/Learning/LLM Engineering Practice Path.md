# LLM Engineering Practice Path

The illustrated LLM Engineer Playbook offers an eleven-chapter practical reading path: model foundations, datasets/training, fine-tuning, inference optimization, local tooling, RAG/memory, agents/workflows, model families, deployment, evaluation and real-world integration.

## Source exercise anchors
- Chapter 1: examine token behavior with a short completion task.
- Chapter 2: create five small supervised-training examples.
- Chapter 3: compare a quantized model artifact's file size with its full-precision context.
- Chapter 5: inspect a local model workflow.
- Chapters 6–7: connect retrieval and tools to a bounded task.
- Chapter 10: evaluate behavior against a dataset rather than infer quality from one fluent answer.

These are source learning exercises. Hardware/runtime commands and model names must be checked against current official documentation before installation; this note claims no completed download, trained model or benchmark.

## Practice record
Chosen chapter / source section / task / environment / data permission / expected output / observed output / model and prompt version / failures / cost or runtime / reviewer / next change.

Training examples must respect approved data use. Local inference does not automatically establish privacy if the workflow sends inputs to a remote service. Use [[Learning Reference Editions]], [[Artifact Review Rubric]] and [[Prompt Evaluation Record]].
