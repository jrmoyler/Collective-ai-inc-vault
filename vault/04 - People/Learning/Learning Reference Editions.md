# Learning Reference Editions

These are separate Drive artifacts, even when filenames repeat. Read them as source editions rather than silently overwriting one with another.

| Source edition | Role | Reading treatment |
|---|---|---|
| Employee Studybook COMPLETE | Operator reference; domain chapters and build layers | Conceptual/architectural grounding before exercises |
| Employee Studybook, Drive ID ending U-pjr | Extended working knowledge base | Chapter path and source-specific terminology |
| Employee Studybook, Drive ID ending 2Q2VZ | Academic expanded source edition | Reference behind curriculum, handbook and workbook |
| Reference Handbook | 100-page source-guide edition | Scan chapter, study definitions, practice, return for clarification |
| Handbook / Workbook | 96-page practice companion | Read → practice → build inspectable artifacts |
| Technical Learning & Build Curriculum V2 | 24-week assignment map | Role track and staged build sequence |

Page counts and duration are source labels; completion is not recorded. The two identically named studybooks have different extracted content and must retain their Drive IDs.

## Source learning rules
The reference handbook does not replace primary documents or permit bypassing Aegis/clinical/legal/security/physical review. The workbook asks for a small artifact tied to a real Collective AI product/node, then a bounded prototype. Unknown terms and open questions belong in the learner's record.

Use [[Team Learning Path and Competency Gates]], [[Workbook Artifact Record]] and [[Artifact Review Rubric]]. Model routing, director tiers, active divisions and veto powers remain governed by AGENTS canon when source editions disagree.
