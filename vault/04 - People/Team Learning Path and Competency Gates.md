# Team Learning Path and Competency Gates

The V2 curriculum is a **24-week proposed study-and-practice path**. Its 600+ agent lattice is a target in the source, not a live-agent count.

## Execution chain
Idea → product specification → interface → codebase → data model → AI/agent layer → automation → governance → deployment → operating documentation.

## Role tracks
| Track | Focus | Required evidence named by the source |
|---|---|---|
| Founder / Architect | Operating model, Synergy Nodes, roadmap, Aegis | Source map and architecture decisions |
| Builder / Engineer | Coding, APIs, auth, database, deployment | App shell, Knowledge Keeper API, deployed site |
| Designer | Brand, components, responsive UX, accessibility | Component system and handoff |
| AI Product Manager | PRDs, workflows, evaluation and acceptance | PRD, workflow diagram and delivery checklist |
| ML / Agent Engineer | RAG, tools, evaluations and model routing | RAG assistant, eval bench and MCP server |
| Physical AI Builder | Compute, sensors, network, fabrication and safety | Herald Badge/Zenith Oracle spec and network map |
| Security / Governance | RBAC, secrets, threat models and audit | Review queue, access policy and safety evidence |

Everyone completes Weeks 1–6. Engineering roles complete Labs 03–08. Physical roles remain bench-only until Aegis-Hold safety review. Everyone producing client output completes the production QA and Aegis modules.

## Competency progression
Beginner demonstrates terms and safe editing. Intermediate delivers a bounded working feature. Advanced delivers an integrated system with auth, logs, tests, failure handling and operational evidence. Apply this progression independently to coding, design, ML, LLM control, agents, tools, automation, knowledge systems, product management, physical AI and governance.

Use [[SOP — Team Onboarding]] to assign tracks and [[Artifact Review Rubric]] to review actual work. Completion dates and scores remain blank until reviewed.
