## Provider registry boundary
The source catalog covers model access, search, image/video and voice generation, automation, data stores, payments, communications, maps/weather, analytics, security and financial datasets. These are vendor categories for evaluation, not an inventory of verified integrations. Use [[Tool Evaluation and Routing Contract]] before assigning active status. Existing reference tools are linked from [[Collective AI Tool Stack]] and [[External Toolkit — 130 Tools]].

## Architecture connections
MCP exposes callable tools; an API defines the underlying service interface; a knowledge graph defines relationships and provenance. A shared vendor name across these layers does not prove an integration. Link each interface to its tool contract, source record, test evidence and decision before routing live work.
