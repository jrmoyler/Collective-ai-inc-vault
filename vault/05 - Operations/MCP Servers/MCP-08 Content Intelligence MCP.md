# MCP-08 Content Intelligence MCP

Custom MCP server 08 of 20 in the [[MCP Matrix]]. Owner: [[Nexus Labs Division]]. Also used by: Signal Velocity, ZenFlow. Status: to build.

[[Nexus Labs Division]] is one of the 9 operating divisions.

## Purpose

Nexus Labs content performance MCP. Aggregates multi-platform analytics, surfaces trending formats, identifies content gaps, and generates production briefs based on performance data.

## Tools (7)

Inputs and outputs come from the build prompt. Where the matrix gives only the tool name, the cell says so.

| Tool | Input | Output / behavior |
|---|---|---|
| `get_platform_analytics` | platform, period | Aggregated reach, engagement, conversion |
| `get_trending_formats` | (none) | Trends from TikTok Creative Center + YouTube Trending + Reddit r/marketing |
| `identify_content_gaps` | Not specified in the matrix | Not specified in the matrix |
| `generate_production_brief` | topic, platform, target_audience | Structured brief generated by the Claude API with performance context |
| `get_virality_score` | Not specified in the matrix | Not specified in the matrix |
| `compare_content_types` | Not specified in the matrix | Not specified in the matrix |
| `schedule_post` | content, platforms, datetime | Dispatches the post to Buffer/Later |
