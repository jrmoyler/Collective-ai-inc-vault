# SOP — Client Onboarding

**Owner:** [[Kenza Dawkins]] · **Agents:** [[Proposal_Builder]], [[Scope_Guardian]] · **System:** [[Airtable Operations Hub]]

## Stage 1 — Intake (day 0–2)
- [ ] Log the lead with source, contact, need and budget range
- [ ] Qualify: real problem, decision maker, budget, timeline
- [ ] Pick the **lead division** using the dossier rule: the division whose domain holds the client's core value proposition leads. [[The Collective Division]] stays venture architect and client-integration owner unless the charter says otherwise
- [ ] For SOLOFORGE work, name at least three active divisions (Synergy Mandate)

## Stage 2 — Proposal and agreement (day 2–7)
- [ ] Discovery call notes saved to the client's note
- [ ] Proposal and SOW from [[Proposal_Builder]]: scope, deliverables, out-of-scope list, milestones, acceptance criteria, price
- [ ] Payment terms written down. Default for small creative work is full payment before work starts (as with [[Chanel Taylor Channel Package]]). Larger work uses milestone billing
- [ ] Data handling: anything with PII, financial or health data is Aegis-Review minimum
- [ ] Signed agreement and invoice number in the client's billing series ([[Client Billing Ledger]])

## Stage 3 — Kickoff (week 1)
- [ ] Kickoff call: goals, success metrics, communication channel, meeting cadence
- [ ] Access collected through the client's own sharing tools. Never take passwords over chat or email
- [ ] Shared folder and task board created
- [ ] First deliverable date confirmed

## Stage 4 — Delivery and change control
- [ ] Every change request goes to [[Scope_Guardian]] first, then a written change order
- [ ] Weekly status in [[Weekly Ops Sync]]

## Stage 5 — Close
- [ ] Acceptance sign-off
- [ ] [[ROI_Calculator]] outcome summary
- [ ] Case study only with written client permission ([[Case_Study_Scribe]])
- [ ] Ask for referral and testimonial. Testimonials must be real and unedited in meaning ([[SOP — Content Publishing]])
