# Financial Forecast Assumption Register

## Scenario definition
Model name / version / horizon / owner / currency / source date / purpose / actual baseline / approved forecast status.

| Assumption family | Required evidence |
|---|---|
| Demand | Actual signed work, qualified pipeline and conversion assumptions |
| Price | Current offer or reviewed quote, renewal and discount/scope rules |
| Volume | Capacity, adoption, churn and measurement period |
| Cost | Vendor bills, labor, cloud use, taxes and infrastructure estimates |
| Timing | Collection dates, deposits, milestones and funding availability |
| Activation | Operating versus chartered versus pending division state |
| Dependencies | Upstream release, clinical/legal review and supplier conditions |
| Risk | Low/base/high scenario, evidence gap and sensitivity |

## Historical source review
The January 2026 pro forma assumes service-first funding before infrastructure-first scale. Its large revenue/customer/valuation forecasts require new evidence and cannot become actuals simply by being imported. See [[Strategic Financial Pro Forma — January 2026]].

The source treats autonomous compliance and margin improvements as assured. A review record must distinguish an implemented control from an intended one and an estimate from measured cost savings.

## Review output
Record assumptions changed, material driver, cash consequence, downside scenario, decision owner and next verification. CFO routing is [[Ahmad Muhammad]]. Current facts and near-term targets live in [[Financial Position]] and [[Revenue Plan — $21.7K per Month]].
