# Design Rule Reconciliation Record

## Source precedence
Design System Bible v3 specifies parent components, spacing and ten universal rules. The designer-facing guide allows legible secondary reading typography and print-specific treatment. User instructions for this work also reject AI-brain imagery, particle backgrounds and generic geometric decoration. Do not blindly restore prohibited motifs just because an older source illustrates them.

## Record the actual decision
| Area | Source constraint | Implementation decision needed |
|---|---|---|
| Identity | Parent versus division versus cross-portfolio | Applicable brand and allowed marks |
| Color | Parent #050A18 / #D4A843; division accent ownership | Exact tokens from current [[Color Locks]] |
| Typography | v3 calls Space Grotesk universal with JetBrains Mono for data; designer guide permits neutral dense-reading type | Current approved reading font and surface |
| Spacing | 8px base with 4px detail; named 4–64px tokens | Consistent token system rather than arbitrary offsets |
| Text placement | Curriculum prohibits text over images | Stable readable panels for dense content |
| Motifs | Older v3 lists star fields/brain medallions/geometric accents | Omit motifs explicitly rejected by current user direction |
| Activation | v3 cover says 20 active divisions | Nine operating, eleven chartered; pending 21–30 remain pending |

## v3 component anchors
Primary button: gold field, navy text and 12×24px padding. Card: #0D1326 field, #1A2540 boundary, 24px padding and restrained accent edge. Input: #111827 field and visible gold focus boundary. Modal: dark scrim, #0D1326 surface and clear heading. These are source anchors to review, not evidence every product uses the components.

Keep one division's primary accent per asset; cross-division work uses parent gold. The parent tagline stays parent-level. Persona informs density and visual treatment, and unnecessary decoration is removed.

Use [[Designer Production Brief]] and [[Design System Bible v3]]. Record approved deviations rather than silently merging conflicting editions.
