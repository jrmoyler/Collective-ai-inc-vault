## Designer-facing application layer
The full Human Designer Brand & Application Guide explains how to apply the system across websites, product interfaces, decks, PDFs, social assets and internal tools. [[Designer Production Brief]] captures the identity/surface/register/asset decisions that precede implementation.

The application guide separates brand rules from components: use parent/division identity rules to choose visual intent, then token/component definitions to implement. The guide uses an 8px base grid, 4px detail rhythm, one primary action per frame, dark-first surfaces and legible reading typography. Print/long-form reading can use light backgrounds where readability improves.

## Release review
- Confirm parent versus division versus Synergy Node identity.
- Match [[Color Locks]] and [[Division Palettes]].
- Keep the parent tagline on parent materials only.
- Use parent navy/gold for corporate umbrella surfaces.
- Use neutral reading typography for dense operator content.
- Document responsive, hover, focus, validation, loading and empty states.
- Put text on stable high-contrast surfaces rather than busy imagery.

The source is guidance, not evidence that all 35 Figma pages or deployed products were re-audited.
