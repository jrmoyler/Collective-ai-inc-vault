# Designer Production Brief

Complete the guide's four opening questions before layout work:
1. Which identity is expressed: parent, division or Synergy Node?
2. Which surface is being made: marketing, operator interface, cohort experience, print, social or document?
3. Which emotional register is required: authority, speed, trust, education, community or experimentation?
4. Which assets are permitted, restricted or mandatory?

## Shared identity rules
Parent identity uses deep navy #050A18 and amber gold #D4A843, with Space Grotesk carrying headline presence. Parent materials communicate portfolio coherence. The parent tagline belongs on parent assets, not inside a division logo or division landing page. A subtle four-point parentage mark can acknowledge affiliation without competing with the division identity.

## Layout and typography
- Default to dark surfaces unless long reading or print benefits from light backgrounds.
- Use an 8px rhythm and 4px detail grid.
- Keep one primary action per frame/section.
- Use asymmetry and compartmentalization only when they improve hierarchy.
- Use Space Grotesk for headlines and concise identity moments; use a legible body face for dense tables, forms and long text.
- Use weight contrast before extreme size differences.

## Color ownership
The guide reserves cyan for Animus Prime. Do not replace parent gold with a division accent on umbrella assets. Consult [[Color Locks]] and [[Division Palettes]] for exact division ownership; do not infer an extra active division from an older catalog.

## Handoff record
Surface / identity / audience / primary action / palette tokens / type roles / allowed marks / source edition / responsive states / accessibility findings / approved assets / reviewer.

Brand guidelines determine identity and tone; the token schema and component library determine coded behavior. Link [[Design System Bible v3]] and [[Website Production Checklist]].
