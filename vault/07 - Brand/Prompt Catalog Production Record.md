# Prompt Catalog Production Record

## Historical catalog scope
The 2026 Updated Prompt Catalog labels **373 products, 21 catalog sections, 21 signature pieces and 21 khaki-pants entries**. Its 21 sections include the parent company plus twenty divisions. Do not treat its cover phrase “21 Divisions” as activation canon or create an extra division.

## Production fields
Product name / catalog ID / parent or division / source edition/page / silhouette / material and texture / palette / logo and placement / visible construction details / view/angle / lighting intent / required output / rights and source asset / reviewer.

The source describes apparel, footwear and accessories and provides mockup prompts. Its listed prices are historical proposed catalog prices, not collected revenue, live stock or approved offers. Model settings and product-platform names are dated examples rather than guaranteed current interfaces.

## Review before generating
- [ ] Use the actual named brand and current color locks.
- [ ] Preserve described seam, fit, trim, logo position and material behavior.
- [ ] Avoid unapproved brain/particle/geometric visual clichés under current user direction.
- [ ] Separate parent branding from division assets.
- [ ] Label mockups; never imply a rendered garment was manufactured or sold.
- [ ] Record tool/output and inspect the result against the source requirement.

This record does not spend generation credits or publish an image. Link [[Designer Production Brief]], [[Design Rule Reconciliation Record]] and [[Financial Position]].
