# AI Architecture Research Map

The Architectural AI 2026 Field Guide is an educational architecture survey. Its market status/ranking statements are source claims, not a current validated technology forecast.

| Family | Source study focus |
|---|---|
| Foundation and sequence | Transformers, state-space/Mamba, mixture-of-experts |
| Reasoning and orchestration | Agent memory, hierarchical reasoning, multi-agent systems and test-time compute |
| Generation and perception | Diffusion, vision transformers, multimodal-native systems, CNN/ResNet |
| Structured representation | Autoencoders and graph neural networks |
| Grounding | Retrieval-augmented generation |
| Frontier research | Neuromorphic/spiking systems and quantum-AI hybrids |

## Architecture investigation record
Problem / input and output / constraints / candidate family / cited paper / date and review status / measured task / resource requirements / quality/latency/cost comparison / failure modes / integration boundary / decision.

Use the family map to select reading, then verify the underlying primary research before selecting a production stack. Quantum, neuromorphic and architectural predictions remain research topics until measured feasibility and the current project requirement justify them.
