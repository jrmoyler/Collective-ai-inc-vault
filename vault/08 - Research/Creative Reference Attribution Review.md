# Creative Reference Attribution Review

> [!warning] Source contains a contradictory attribution
> The Creative Knowledge Base first labels Kader Attia as a Studio Ghibli co-founder associated with Spirited Away/Howl's Moving Castle/Princess Mononoke. Later it describes Kader Attia as a French-Algerian artist concerned with repair and colonial aftermath. These are inconsistent source entries. Do not ingest that biography as verified fact.

## Useful source taxonomy
The guide groups anime/manga creators, typography/art direction, modern/contemporary visual artists and animation history. That organization can guide a reference search without treating every biography, ranking or numerical claim as checked.

## Attribution record
Name / claimed role / work cited / source section / independent primary reference / confirmed attribution / date reviewed / disputed fields / permitted creative use.

## Disposition
The contradictory entry is quarantined pending primary-source verification. Other artist biographies and claims remain unverified unless separately checked. A reference list is not permission to reproduce a living artist's protected work or an established character asset.

Use verified references to describe concrete composition, medium, pacing, materials and production technique. Link [[Campaign Evidence Register]], [[Designer Production Brief]] and [[Nexus Labs Division]].
