# Agent Shuffle

AGENT SHUFFLE is a dark-mode visual intelligence platform for the Collective AI agent ecosystem. It imports the master agent roster and overseer PDFs and normalizes the 20-division agent lattice.

## Features

- Importer extracts the ZENITH overseer, 20 divisions, 20 division directors, 600 specialist agents, tool stacks, prompts, relationships and 20 synergy nodes.
- Pages: dashboard, agent directory and profiles, division explorer, `/overseer` (ZENITH routing view), `/synergy`, `/builder`.
- Builder scores a team for coverage, overlap, gaps, diversity, effectiveness, complexity, synergy and Aegis risk.
- Raster PNG illustrations only; no SVG assets or SVG chart libraries.

## Tech stack

Next.js 15, React 19, TypeScript, Tailwind, Framer Motion, Zustand, Prisma (SQLite locally, Postgres-ready).
