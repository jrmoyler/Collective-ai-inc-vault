## Features

- Single-file React SPA with services, pricing plans, about, FAQ and contact.
- Plan prices in the code include $225, $350 and $1,200.
- Intake form with controlled state that creates an account on submit (May 12, 2026).
- Typography and contrast fixes for readability.

## Tech stack

React 19, Vite 8, Tailwind v4; Cormorant Garamond and DM Sans.
