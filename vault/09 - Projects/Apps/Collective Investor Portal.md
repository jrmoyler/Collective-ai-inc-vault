## Features

- Discovery grid, sortable tracker table, priority board (Best to Contact, Warm Intros, Recent Activity).
- Drag-and-drop Kanban from Unresearched to Potential Investment.
- Research terminal, email console for outreach drafts, investor map.
- Six 0–100 scores per investor: Fit, AI, Columbus, Check Alignment, Recent Activity, Outreach Readiness.

## Tech stack

Static front end plus Express-style serverless API routes (`api/investors.js`, `api/research.js`, `api/emails.js`).
