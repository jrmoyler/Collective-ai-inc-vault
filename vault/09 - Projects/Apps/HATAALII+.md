# HATAALII+

A personal entertainment discovery app built for JR Moyler. It replaces algorithmic feeds with a small number of chosen picks per day, explainable scoring, verified availability and a Model Council review that gates releases against echo-chamber recommendations.

## Features

- Today's Channel: one slot per shape of attention (lead feature, short watch, deep watch, hands-on/game, listen, read, wildcard).
- Tonight Mode: three options (Safe Bet, Real Discovery, Wildcard) from mood, time and energy.
- Weekend Programming plus 38 curated Central Ohio events; Discover lists all 73 catalog items; four editorial channels.
- My Library, History, and Settings that expose the scoring weights.
- Scoring is deterministic and rule-based; LLMs are used only offline for the Model Council pass.

## Tech stack

React + Vite, Express, Radix UI, Tailwind, Drizzle, Supabase client.
