# Memory Galaxy

A 3D visual knowledge graph where memories, projects, documents, ideas, agents and relationships become a living galaxy. Galaxy = domain, solar system = project, planet = knowledge base, city = document, building = concept, citizen = fact, wormhole = semantic relationship.

## Features

- Full-screen React Three Fiber galaxy with nebula, hyperspace-lane relationships and zoom-to-object camera flights.
- Typed mock hierarchy of 38 nodes and 45 relationships; Supabase-ready data layer.
- Inspector with suggested AI actions (summarize, find related, next steps, project brief, export markdown) returning mock responses.
- Navigator with search, filters and bookmarks; command bar ("Ask your galaxy anything…") with commands like `show zenflow`.

## Tech stack

React 19, React Three Fiber 9, drei 10, three 0.185, postprocessing, TanStack Query, Zustand, zod, Tailwind.
