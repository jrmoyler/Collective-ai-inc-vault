## Features

- Assessment engine (`/assessment`) and results with radar chart and top roles.
- AI career report generator (`/api/prism-report`); falls back to deterministic output without an OpenAI key.
- Candidate database, admin hiring dashboard (protected by middleware), talent analytics.
- Shareable profile at `/profile/[username]`. Anonymous users can take the exam; only signed-in users persist reports.

## Tech stack

Next.js 14, Supabase (email + Google OAuth), Recharts, Framer Motion, Tailwind.
