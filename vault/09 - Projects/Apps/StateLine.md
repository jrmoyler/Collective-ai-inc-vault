# StateLine

Licensing and certification exam prep for 23 credential tracks on one clickable map of all 51 US jurisdictions. Pick a credential and a state and get a study hub: audio lessons, summary guide, practice test and flashcards.

## Features

- 23 tracks × 51 jurisdictions = 1,173 verified coverage units. Unpublished fees or passing scores show as `unconfirmed`, never an industry average.
- State tracks: L&H insurance, CPA, esthetician, cosmetology, nail tech, barber, massage, PMU, lash, brow.
- Federal tracks: PMP, CSM, Security+, CISSP, AWS SAA, GCP PCA, AZ-104, EA, AFSP.
- National-plus-state tracks: CRS, RENE, PSA, e-PRO.
- Founding track is Life & Health insurance, with state-specific passing scores and vendors (e.g. Montana scaled 75, California 60% with PSI).

## Tech stack

Static site with Node verification scripts (`npm run verify:coverage`).
