# The Forge Learning Studio

A private training system built from *The Forge Personal Field Guide* by John-Ross Moyler / Hataalii. Owners invite mentors and learners, assign missions, and mentors score submissions against a rubric. The campus is a navigable 3D academy.

## Features

- Owner enrollment link (kept private), seven-day single-use invitations for mentors and learners.
- Missions with due dates; learners read, practice, pass a server-scored knowledge check and submit an artifact with evidence.
- Five-part mentor rubric: 80/100 with no critical failure awards mastery. Nobody reviews their own submission.
- Curriculum: 94 pages, 15 model cards, 66 tool cards and more from the private source guide.
- Five navigable 3D districts (Three.js) with an SVG fallback for browsers without WebGL.

## Tech stack

React + Vite, Three.js, Supabase (project in US East Ohio), PGlite for local tests.
