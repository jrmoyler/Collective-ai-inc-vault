# Civic Core — Digital Champions

CIVIC CORE: DIGITAL CHAMPIONS is a 2D mobile-first side-scrolling action platformer. "The Core is for everyone. We fight not just for access — but for a future where every voice can build."

## Features

- Move, jump, basic attack and a Civic Ability; world map; pause; collision debug overlay.
- Virtual joystick and on-screen JUMP / ATK / ABILITY buttons on mobile.
- Three zones with tilesets; hero, enemy, boss/NPC, UI and collectible sprite sheets.
- Matter.js physics, Three.js 3D parallax background, Phaser FX and object pooling (May 26, 2026).

## Tech stack

Phaser 3, Three.js, TypeScript, Vite.
