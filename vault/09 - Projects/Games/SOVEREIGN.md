# SOVEREIGN

A cinematic 3D real-time strategy game in the browser: Age-of-Empires-style play reimagined as Collective AI Inc. becoming a full-stack AI civilization. You lead any of the 20 divisions and race rival divisions to build Sovereign Intelligence. It is the SOVEREIGN entry in the [[Collective Games Suite]].

## Features

- Win by completing the 8-stage stack before any rival: Compute Supremacy → Data Dominance → Talent Network → Trust Threshold → Governance Clearance → Recursive Agent Breakthrough → Physical Infrastructure Lock-in → Sovereign Intelligence Activation.
- Military conquest only slows rivals; the race is economic and technological.
- Faction-distinct procedural architecture, day/night cycle, rival AI, audio, trackpad-first controls and mobile touch controls.
- No build step: Three.js r169 vendored, plain ES modules, served by `serve.py` or any static server.

## Tech stack

Three.js (vendored), plain ES modules, Python static server.
