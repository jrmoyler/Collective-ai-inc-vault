# MVP Build Lanes

The guide sorts every catalog item into one of four build lanes.

| Lane | Recommended interpretation |
|---|---|
| Build now | Active/revenue/proof platforms: ZenFlow, The Collective, Hybrid Living, Nexus Labs, Quantum Ledger, Signal Velocity, Juris Guard. |
| Build as simulator | Regulated or hardware-heavy systems: Helios Grid, robotics, autonomous logistics, health/longevity clinical products. |
| Build as admin shell | Governance, reporting, analytics, compliance, API portals, dashboards, and registries. |
| Do not deploy live yet | Energy trading, medical recommendations, robot/autonomous systems, securities/investment execution without review. |

> [!info] Canon check (Oct 4, 2026)
> The operating divisions are ZenFlow, The Collective, Hybrid Living, Nexus Labs, Signal Velocity, Quantum Ledger, Binary Loom, Obsidian Arc, and Juris Guard. The guide's "Build now" lane lists seven of these; Binary Loom and Obsidian Arc are operating but sit in later stage labels in the guide. Helios Grid stays blocked pending an SEC legal opinion.

## Lane by division

- Build now: [[ZenFlow Division]], [[The Collective Division]], [[Hybrid Living Division]], [[Nexus Labs Division]], [[Quantum Ledger Division]], [[Signal Velocity Division]], [[Juris Guard Division]]
- Build as simulator: [[MVP — Helios Grid]], robotics ([[Animus Prime Division]]), autonomous logistics ([[VectorShift Division]]), clinical health and longevity ([[Vital Helix Division]], [[Eon Core Division]])
- Build as admin shell: any governance, reporting, analytics, compliance, API portal, dashboard, or registry MVP

## Design requirement

Use Collective AI parent colors as the shell, but every product page must also carry its division palette and UI mood. Brand unity comes from layout, typography, headers, spacing, and governance labels; product differentiation comes from division-native color, microcopy, and interface metaphors.
