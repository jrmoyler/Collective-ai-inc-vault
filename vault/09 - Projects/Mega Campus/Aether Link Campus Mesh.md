# Aether Link Campus Mesh

Campus network of the [[Collective AI Mega Campus]]. Canon term: **Aether Link = 5G mesh + 400G fiber backbone** (v3.0 figure, not restated in the Sept 16 register for the 400G figure; the register does not state bandwidth). Owned by the [[Aether Link Division]].

## What the Sept 16 package supports

- [[Aether Link Mesh Operations Spire]] (CF-20, 25,000 sq ft, 2 floors, 300 ft / 91.44 m): mesh operations, field terminal sync, network lab, translation QA, spectrum monitoring, signal command, failover control, antenna systems.
- Reference artwork: asymmetrical glazed spire, stepped occupied rooms, external braces, circular antenna crown and needle; the explorer models an antenna deck, eight equipment masts and a central aerial.
- 10 mesh spires across the site, each with a Blender-authored synergy node (`public/models/synergy-node.glb`), shown in the "Mesh spires & data links" layer.
- S13 program card: 5G/LoRa/Wi-Fi mesh, MQTT bridge, failover network, field terminal sync, spectrum monitoring.

Earlier Aether Link specs (Q1 2026: five 300 ft spires, N78 sub-6 GHz, Clone Alpha 5G slice) are in [[Mega Campus Version History]].
