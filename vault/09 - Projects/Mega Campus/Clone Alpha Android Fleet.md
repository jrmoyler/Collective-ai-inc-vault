# Clone Alpha Android Fleet

**Clone Alpha** is the canon name for the campus biomimetic android fleet of the [[Collective AI Mega Campus]], from the [[Animus Prime Division]] ([[Prime Directorate]] line). **Nexus Hub** is the canon name for android docking and charging.

## What the Sept 16 package supports

- [[Titan Works]] (CF-08, 200,000 sq ft): robotics assembly, android assembly, machine integration, safety test lanes.
- The explorer's outdoor fleet includes androids alongside autonomous shuttles, freight trucks, drones and pedestrians (about 290 agents on defined paths); PR #15 (Sept 23, 2026) added photoreal fleets and a fleet camera.
- The register has no separate Nexus Hub building. Docking and charging location is not stated.

The Q1 2026 per-unit spec (48 DOF, 80 kWh pack, 50-unit Phase 1 fleet, 50-bay Nexus Hub) and the Ghana 1,000-unit fluid-compute concept are earlier designs, summarized in [[Mega Campus Version History]].
