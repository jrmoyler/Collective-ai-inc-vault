# Mega Campus Security and Governance Systems

Security and governance facilities of the [[Collective AI Mega Campus]]. **Obsidian Arc** is the canon security system ([[Obsidian Arc Division]]); [[Aegis Protocol]] gates and [[Knowledge Keeper]] logging appear throughout the S13 program cards.

## Facilities in the register

- [[The Vault]] (CF-03, floors B1-B2): treasury operations, risk command, Watchtower command, evidence transfer, cold storage vault, Faraday suite, incident response.
- [[Juris Guard Regulatory Command Wing]] (CF-19): evidence intake, privileged review, Aegis review, policy ledger.
- [[Visitor, Security and Campus Operations Center]] (CF-22): screening, badge intake, emergency operations, access control, incident review.
- [[The Trust Vault — Sovereign Key]] (CF-30, pending division): identity operations, credential lab, consent review.

Explorer audits stress that secure systems are represented architecturally only, with no claim of surveillance operation. The v2.0 security zones 0-4 are in [[Mega Campus Version History]].
