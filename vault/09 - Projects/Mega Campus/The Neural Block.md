## S13 program card

The register cites the "S13 program" for this facility: card #02 *The Neural Block* in the June 2026 Updated Blueprint v2.0 (owner line: ZenFlow + Binary Loom compute). The register's area and floor count govern; the card supplies function and intent.

| Field | S13 program |
|---|---|
| Function | ZenFlow agent operations, Binary Loom infrastructure, data center, model routing, telemetry, internal platform R&D. |
| Architectural features | Partially submerged matte-black brutalist structure; glass mission control; liquid-cooling visual feature; secure operations gallery. |
| Infrastructure | Direct liquid cooling, GPU racks, redundant power, 10x backup generators, cooling towers, Kong/API gateway, OpenTelemetry and [[Knowledge Keeper]]. |
| Governance / safety | Aegis middleware, uptime monitoring, isolated production networks, human override path. |

Earlier v3.0 counterpart (superseded): Neural Block Data Center, 1,036,800 sf, 96 MW critical IT. See [[Mega Campus Version History]].
