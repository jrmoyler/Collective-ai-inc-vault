## What it is

A dedicated voice/display broadcast terminal for the parent brand. Presents live portfolio metrics, division status dashboards, and brand narrative on a Whisplay display — always on, always branded.

## Outcome

Always-on ambient brand terminal — portfolio metrics display, voice-query, division status broadcast.
