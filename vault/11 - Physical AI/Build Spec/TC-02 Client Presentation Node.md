## What it is

A conference-room Pi node with far-field mic, ambient display, and camera presence detection. Activates AI-assisted presentation mode when a client enters, logs session notes, and sends a post-meeting summary to the Mac mini.

## Outcome

AI-assisted client presentation terminal — presence detection, session recording, post-meeting summary.
