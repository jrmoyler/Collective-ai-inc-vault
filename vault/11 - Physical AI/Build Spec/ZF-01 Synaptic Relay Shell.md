## What it is

A dedicated Pi 5 shell that sits beside each department desk, accepting voice prompts, routing them to the ZenFlow Mac mini orchestrator, and reading back agent responses. The physical manifestation of the ZenFlow routing layer.

## Outcome

Department-level ZenFlow voice relay — prompt input, agent response output, local routing log.
