# OA-02 Obsidian Arc Security Drone — Pose Sheet — Prompt

**Device:** OA-S6 Sentinel Drone · **Mode:** MODE 3 — Character Pose Sheet · **Aspect ratio:** `--ar 3:1`

**Division(s):** [[Obsidian Arc Division]]
**Director agent(s):** [[Director_Obsidian_Arc]]
**Catalog location:** Part 1 — Drone Fleet › Obsidian Arc (*The Eye That Never Closes.*)
**Hub:** [[Hardware Agentic Prompt Catalog]]

## Purpose
Generate a character pose sheet of the OA-S6 Sentinel Drone: one unit shown in several poses on one sheet.

## When to use
Use when you need consistent poses of one unit for storyboards, animation reference or later video work.

## Inputs
- Target model: Nano Banana 2, GPT Image 2, Midjourney, Grok Imagine (stated for Part 1).
- No variables. Paste the prompt as written; it ends with its own `--ar` flag.

## Prompt
```
a character sheet containing several poses of a one Obsidian Arc OA-S6 security surveillance drone, matte obsidian black hexagonal body six rotors, multi-sensor turret undercarriage, poses include patrol hover, spotlight lock, threat intercept dive, perimeter orbit, emergency ascent return, hard surface technical illustration flat color style --ar 3:1
```

## Expected output
One wide sheet showing the same unit in each listed pose.
- Poses to check: patrol hover, spotlight lock, threat intercept dive, perimeter orbit, emergency ascent return.
