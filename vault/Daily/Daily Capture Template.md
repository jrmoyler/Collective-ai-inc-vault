# Daily Capture Template

This is a blank work record derived from the Personal Assistant Guide's operating rhythm. It records work when it occurs; it does not fabricate a daily update.

## Context
Date/timezone / author / current priorities / source changes / actual assigned tasks.

## Workstreams
| Stream | Capture |
|---|---|
| Client delivery | Actual deliverable, promised date, observed state and blocker |
| Revenue/payment | Offer or invoice ID, due date and confirmed status |
| Synergy Node build | Current scope, participating operating divisions and evidence |
| Infrastructure | Agent/workflow/vault change and relevant check |
| Content/community | Draft or approved publication and measured response |
| Research/strategy | Source, decision needed and evidence gaps |

## Priority order from the May 2026 guide
Client errors/delays → revenue/payment → pending client communication → approved Phase 1 work → infrastructure → content/community → research/strategy. Historical examples in that guide do not establish today's clients or projects; consult [[Weekly Ops Sync]] and live tasks.

## Decisions and next work
Decision / owner / alternatives / source / approval if required / next action / due date / unresolved risk.

## End-of-session record
Completed / review needed / blocked / actual tool changes / notes touched / next owner. Link [[Decision Record Template]], [[Project Delivery Record Template]] and [[005 — Operations MOC]].
